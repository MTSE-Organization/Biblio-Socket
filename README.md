## 🔧 Techstack:

- **NestJS**
- **TypeScript**
- **Redis**
- **RabbitMQ**

## 🚀 LAUNCH APPLICATION:

### 1. Configure information in **docker-compose.yml**

### 2. Start services:

```bash
docker compose up -d
```

### 3. Setup environment variables **.env** from **.env.example** theo information in **docker-compose**

### 4. Run the application

```bash
yarn dev
```
